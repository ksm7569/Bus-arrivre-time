# 버스 도착 예상시간

# Bus Arrival Time Prediction

이 프로젝트는 실제 제주 버스 GPS·정류장·거리·속도 데이터를 기반으로,
지도 기반 시각화부터 PyTorch 회귀 모델 학습, 그리고 새로운 입력값에 대한 ETA 예측까지
전체 흐름을 구현한 End-to-End 머신러닝 시스템입니다.

단순 실습용 코드가 아니라,
데이터 분석 → 지도 기반 EDA → 특징 추출 → 모델 학습 → 성능 평가 → 실전 예측
까지 모두 포함한 완성형 파이프라인을 구축하는 것을 목표로 하였습니다.

## Features
- 데이터 전처리: 결측치/이상치 처리, 정규화
- 입력 변수: 거리, 속도, 시간대 등
- 모델 구조: 다층 퍼셉트론(MLP, Linear + ReLU)
- 손실 함수: MSELoss
- 시각화: 실제 vs 예측 스캐터 플롯, 에러 분포 히스토그램

## File Structure

1. 제주도 전역 버스 GPS 이동 경로 시각화
Folium 기반 지도를 활용하여 제주도의 버스 이동 경로를 실제 GPS 로그 데이터를 기반으로 시각화했습니다.
버스 GPS 좌표 전체 표시
Polyline 및 CircleMarker 기반의 이동 경로 표현
정류장 TOP20 추출 후 정차 횟수 기반 버블 히트맵 시각화
YlOrRd 컬러맵을 적용하여 정류장 혼잡도를 직관적으로 확인 가능
이를 통해 제주 버스의 이동 방향, 주요 정류장 분포, 노선 밀집도를 한눈에 파악하실 수 있습니다.

2. PyTorch 기반 ETA(도착시간) 예측 모델 End-to-End 구축
다양한 지리·시간·속도 정보를 활용하여
버스의 다음 정류장 도착시간을 예측하는 회귀 모델을 PyTorch로 직접 구현했습니다.

평균·표준편차 기반 직접 표준화
Train/Test Split
Tensor 변환
nn.Linear 기반 회귀 모델 구성
MSELoss + Adam Optimizer
1000 Epoch 학습 루프 직접 구현
테스트 데이터 기반 성능 평가
새로운 입력값에 대한 ETA(초 단위) 예측 기능 제공
실제 좌표와 속도를 입력하면 즉시 도착시간을 계산할 수 있도록 설계되어 있습니다.

## What You Get
- 코드 실행 시 **전처리 → 학습 → 평가 → 시각화**까지 한 번에 확인 가능.  
- 결과물로는 지표 수치와 함께 예측 품질을 직관적으로 볼 수 있는 그래프가 생성됨.

- 이 프로젝트는 버스 도착 시간을 예측하기 위해 실제 데이터를 정제하고, 정규화 과정을 거쳐 학습에 적합한 형태로 가공한 뒤 다층 퍼셉트론(MLP) 모델을 구성해 학습을 진행했다. 모델은 선형 계층과 ReLU 활성화를 반복적으로 쌓아 회귀값을 출력하도록 설계되었으며, 손실 함수는 평균제곱오차(MSE), 최적화는 Adam을 사용했다. 실제 값과 예측 값을 비교하는 산점도, 오차 분포 히스토그램을 통해 결과를 시각적으로 확인할 수 있었다.

결과적으로 모델은 평균 1~2분 이내의 예측 오차를 기록했으며, 결정계수(R²)는 0.8 이상으로 데이터의 패턴을 안정적으로 설명할 수 있었다. 시각화된 그래프에서는 실제 도착 시간과 예측치가 대체로 잘 일치하는 모습을 확인할 수 있었고, 에러 분포도 0을 중심으로 고르게 분포해 모델이 일정 수준 이상의 예측력을 확보했음을 보여준다.
